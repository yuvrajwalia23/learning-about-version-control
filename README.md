# Learning about Version Control

Author: Yuvraj Singh Walia

Solving merge conflicts takes conscious effort, but I can do it!

## What I Like About Version Control

I like that version control allows me to track changes,
collaborate with others, and recover previous versions
of my code when something goes wrong.

## What I Find Challenging

I find merge conflicts challenging because they require
careful attention to understand which changes to keep
and how to combine them correctly.
